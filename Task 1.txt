?- house = house.
true.
Same atoms.

?- house = abc.
false.
Different atoms.

?- edge(a,b) = edge(C,b).
C = a.
C matches a.

?- edge(a,d) = edge(C,B).
C = a,
B = d.
C matches a and B matches d.

?- edge(C,B) = edge(a,d).
C = a,
B = d.
The variables match the values.

?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g,h).
A matches a and B matches f(g,h).

?- edge(A,A) = edge(b,c).
false.
A cannot be both b and c.

?- edge(A,A) = edge(b,b).
A = b.
Both positions match b.

?- A = B, B = f.
A = B,
B = f.
A and B are linked to the same value.

?- A = B, B = f, A = e.
false.
A cannot be both f and e.
